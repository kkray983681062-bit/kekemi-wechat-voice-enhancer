# 克克咪 微信语音增强 v1.0.0

首个正式版本。提供 Windows x64 独立 EXE，无需安装 Python。

- 读取当前微信语音通话，一键应用并保持 128 kbps。
- 最近 30 秒编码目标曲线，显示采样率、声道和编码器。
- 自动查找并记住微信安装位置，也可手动选择。
- 点击恢复默认或正常关闭工具时停止增强；新通话需重新应用。
- 深色中文界面与头像图标。

**适配：微信 Windows 4.1.15.56 x64 的已验证引擎文件。其他版本会提示未适配。**

下载 `Kekemi-WeChat-Voice-Enhancer.exe` 可直接使用；ZIP 包含同一 EXE、中文说明和第三方组件许可。`SHA256SUMS.txt` 用于核验附件。

打开微信并接通语音 → 打开工具 → 读取当前状态 → 应用 128 kbps。

界面显示编码目标，不是网络实测速率。不会录音、读取聊天、修改微信安装文件或上传运行数据。

发布内容与使用者确认通过的测试 EXE 字节一致。9 项自动检查通过，覆盖路径保存、未知引擎、空通话、多实例及后台读取时的应用点击。
